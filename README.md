# tds-compliance-2026
TDS Compliance Suite FY 2026-27
An interactive TDS compliance and interest calculator 
built for Resident Assessees under the Income Tax Act, 2025.

## Features
- TDS applicability checker with category-wise rates
- Vendor-wise annual threshold tracker with alerts
- Interest on late deposit calculator (Section 201)
- Challan section and deposit code mapping (ITNS 281)
- Client notification profile setup

## Live Tool
https://taxspec.github.io/tds-compliance-2026/

## Applicable For
FY 2026-27 | Income Tax Act, 2025 | Resident Assessees only
